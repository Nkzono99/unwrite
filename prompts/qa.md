# QA 往復の指示（LLM 用）

段落メモだけで原文の情報が復元できるかを、**独立した 2 つの文脈**で確かめる。
同じ文脈で質問と回答を両方やると、原文の記憶で答えてしまうので意味がない。

## 1. 出題者（原文を見る）

- `unwrite segments <target> [--section N]` を読む。
- 事実を問う質問を作る。目安は内容の文 3 つにつき 1 問。次を優先する:
  数値とその条件、比較の向き（どちらが大きいか・何に依存するか）、因果・理由、仮定と適用範囲、
  引用の帰属（誰が何を示したか）、手順の順序、式の意味。
- 「何が重要か」のような評価を問う質問は作らない。
- `<deck>/.sealed/qa.json` に書く:

```json
[{"q": "質問", "a": "原文に基づく答え", "source": ["s012"]}]
```

## 2. 回答者（メモだけを見る。原文は見ない）

- 新しい文脈（subagent）で、`unwrite memos <target>` の出力と、`qa.json` の `q` だけを渡す。`a` と `source` は渡さない。
- 各質問に、メモだけから答えさせる。根拠の段落番号（¶n）を添えさせ、答えられなければ「不明」と書かせる。

## 3. 採点（出題者の文脈か、もう一つの文脈）

- 回答を `a` と比べ、各項目に `"answer"`, `"paras"`, `"ok": true|false` を加えて `qa.json` を更新する。
- 不合格の質問は、メモの欠落（材料・条件・atoms・流れ）として直す。直したら lint を通し、その質問だけ盲検で答え直させる。
- 回答に原文に無い主張が混じっていたら、メモへの混入（作成時の幻覚）として直す。
